# Lens & Light — Professional Photography Portfolio

A modern, responsive web portfolio built with HTML5, CSS3, and JavaScript, designed to showcase high-resolution photography collections across multiple disciplines including portrait, landscape, wedding, and street photography.

---

## 📸 Portfolio Highlights

- **Visual Showcase:** High-impact hero section with full-bleed background imagery and an integrated call-to-action.
- **Categorized Galleries:** Dedicated views for diverse photography niches:
  - Portrait & Studio Sessions (`portfolio_portrait.png`, `about_portrait.png`)
  - Landscapes & Nature (`portfolio_landscape.png`)
  - Street & Candid Life (`portfolio_street.png`)
  - Weddings & Celebrations (`portfolio_wedding.png`)
- **Interactive UI:** Smooth transitions, responsive navigation, and image presentation handled via custom JavaScript.
- **Responsive Layout:** Mobile-first, flexbox/grid layout styled for fluid rendering across smartphones, tablets, and high-DPI desktop screens.

---

## 🛠️ Technology Stack

- **Markup:** Semantic HTML5 (`index.html`)
- **Styling:** Modern CSS3 (`css/style.css`) with CSS custom properties and responsive media queries
- **Interactivity:** Vanilla JavaScript (`js/script.js`) for DOM interactions and smooth transitions
- **Assets:** High-resolution optimized PNG visuals in `assets/images/`

## 🚀 Live Preview / Local Setup

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/](https://github.com/)<your-username>/photography-portfolio.git
   ```
2. **Open locally:**
   Double-click `index.html` or launch it via VS Code Live Server.

3. **Deploy via GitHub Pages (Optional free hosting):**
   - Go to **Settings** > **Pages** in this repository.
   - Under **Build and deployment > Branch**, select `main` and root `/`.
   - Click **Save**. Your site will be live at `https://<your-username>.github.io/photography-portfolio/`.
